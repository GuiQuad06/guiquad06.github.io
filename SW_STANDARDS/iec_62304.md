# IEC 62304

Medical device software — software life cycle processes.

## Safety classes A, B, C

| Class | Criterion |
|---|---|
| **A** | A software malfunction cannot lead to a hazardous situation |
| **B** | A software malfunction can lead to a hazardous situation resulting in a **minor** injury |
| **C** | A software malfunction can lead to a hazardous situation resulting in a **serious** injury or death |

## Project decomposition

```text
Software System
└── Software Item  (Connectivity 3rd-party chip, SP, CI App)
    └── Software Unit of the CI App
        ├── User Management
        ├── Communication Interface
        ├── Firmware (Drivers, Middleware, FreeRTOS)
        └── Implant Management
```

## Practical notes

- Every **Software System** implies preparing a full IEC 62304 file — this is constraining.
- **Strategy:** define a single Software System rather than several.
