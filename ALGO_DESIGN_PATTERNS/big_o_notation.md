# Big-O Notation

| Complexity | Meaning | Typical example |
|---|---|---|
| $O(1)$ | Time is constant versus data size | Append to a linked list by the HEAD |
| $O(\log n)$ | Time is proportional to the log of the data size — better | Binary search |
| $O(n)$ | Time is proportional to the data size — not great | Linear scan |
| $O(n \log n)$ | Linearithmic — good target for a sort algorithm | Merge sort |
| $O(n^2)$ | Quadratic — not usable for sorting big data | Bubble sort |
