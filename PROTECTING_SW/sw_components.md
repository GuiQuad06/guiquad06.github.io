# SW Components

## SBOM (Software Bill of Materials)

- **Data fields**
  - Supplier name
  - Component version
  - Component name
- **Automation**
  - API specs
  - Software ID
- **Practices & processes**
  - Top-level components
  - Dependencies

## Licenses

- **GPL is copyleft**: GPL libraries cannot be used in a product you plan to sell as-is.
- **Reminder:** copyleft components require that end products using them retain the
  same copyleft conditions.
