# Analysis Tools

- **CycloneDX** — SBOM and dependency listing for a Python environment.
- **SCANOSS** — not free, but can provide the licenses of every component.
- [app.shiftleft.io](https://app.shiftleft.io) — scans a project on a GitHub account.
- **OWASP Dependency-Check** (GitHub) — dependency checker.

[nvd.nist.gov](https://nvd.nist.gov) — vulnerability database.
